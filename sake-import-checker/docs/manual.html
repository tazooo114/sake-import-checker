📘 사케 검색 봇 설치 매뉴얼

이 매뉴얼은 서버나 코딩 지식이 없는 분들을 위해 작성되었습니다. 순서대로 따라 하시면 나만의 사케 검색 봇을 만드실 수 있습니다.

💡 팁: 이 문서를 인쇄하거나 PDF로 저장해두고 체크하면서 진행하세요. (단축키: Ctrl + P 또는 Cmd + P)

🏗️ 1단계: 준비물 챙기기

요리를 하려면 재료가 필요하듯, 봇을 만들려면 아래 프로그램들이 필요합니다.

1. VS Code (코드 편집기)

노트장 같은 프로그램입니다. 여기서 다운로드해서 설치하세요.

2. Node.js (실행 도구)

여기서 다운로드하세요. LTS 버전(왼쪽 버튼)을 받으시면 됩니다.

3. Git (다운로드 도구)

여기서 다운로드하세요. 설치할 때 계속 'Next'만 누르면 됩니다.

🔑 2단계: 회원가입 (무료)

4곳의 사이트에 가입해야 합니다. 모두 무료입니다.

  • Cloudflare: 서버 역할 (가입하기)
  • Supabase: 데이터베이스 역할 (가입하기)
  • Google AI Studio: 인공지능 역할 (가입하기)
  • Telegram: 메신저 앱 설치

⚙️ 3단계: 데이터베이스 설정

Supabase 사이트에서 SQL Editor 메뉴에 들어가 아래 코드를 복사해 붙여넣고 Run 버튼을 누르세요.

-- 이 코드를 전체 복사하세요
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE IF NOT EXISTS sake_imports (
  id BIGSERIAL PRIMARY KEY,
  reported_product_name TEXT NOT NULL,
  category TEXT,
  exporter TEXT,
  origin_country TEXT,
  raw_importer_name TEXT,
  value NUMERIC,
  volume NUMERIC,
  unit_price NUMERIC,
  name_embedding vector(768),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- (나머지 인덱스 및 테이블 생성 코드...)
-- 전체 코드는 BEGINNER_GUIDE.md 파일을 참고하세요
중요: 설정이 끝나면 Project Settings > API 메뉴에서 URL과 Key를 메모장에 꼭 적어두세요!

🚀 4단계: 한방 배포

이제 복잡한 작업은 끝났습니다. 터미널에서 명령어 한 줄이면 됩니다.

1. 터미널 열기

VS Code에서 Ctrl + ` (물결표 키)를 누르면 터미널이 열립니다.

2. 명령어 입력

./scripts/deploy.sh

이 명령어를 입력하면 프로그램이 알아서 설치를 시작합니다. 중간에 물어보는 질문(API 키 등)에 메모해둔 내용을 붙여넣기만 하면 됩니다.

🎉 5단계: 사용하기

모든 과정이 끝났습니다! 이제 다음을 즐기세요:

  1. 관리자 페이지: 엑셀 파일을 드래그해서 업로드하세요.
  2. 텔레그램 봇: 채팅방에 사케 사진을 보내보세요.
